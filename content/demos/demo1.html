Nombre: Ingresa tu nombre.
Tecnología: Validación simple con JavaScript (RegEx) para permitir letras y espacios (2-200 caracteres).
Apellido: Ingresa tu apellido.
Tecnología: Similar al nombre, validado con JavaScript para letras y espacios (2-200 caracteres).
Dirección: Escribe tu dirección completa.
Validación: Permite letras, números y símbolos comunes de dirección (#, ., ,). Longitud: 5-100 caracteres.
Teléfono: Solo números.
Validación: Debe tener entre 7 y 15 dígitos. ¡Mira la validación en tiempo real!
País: Elige tu país de la lista.
Tecnología: Se carga dinámicamente usando la API RestCountries.
